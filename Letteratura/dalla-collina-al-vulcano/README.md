# Dalla collina al vulcano

PWA didattica interattiva su Giacomo Leopardi, pronta per GitHub Pages.

## Pubblicazione

1. Crea un nuovo repository su GitHub.
2. Carica qui tutti i file di questa cartella.
3. In GitHub apri **Settings → Pages** e, in **Build and deployment**, seleziona **GitHub Actions**.
4. Attendi il completamento dell'azione **Pubblica su GitHub Pages**.

La PWA sarà disponibile all'indirizzo mostrato da GitHub. Ogni aggiornamento inviato nel ramo `main` verrà pubblicato automaticamente.
