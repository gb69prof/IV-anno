# La Biblioteca di Ugo Foscolo

PWA didattica autonoma collegata alle lezioni presenti in `../Foscolo/lezioni`.

## Funzioni

- accesso ai testi per opera, tema e cronologia;
- collegamenti profondi tra passi originali e lezioni;
- fonti digitali ed essenziali note filologiche;
- ricerca e filtri;
- preferiti, appunti locali ed esportazione;
- installazione PWA e consultazione offline;
- interfaccia responsive e accessibile, pensata anche per iPad.

## Criterio editoriale

I testi di Ugo Foscolo sono di pubblico dominio. Le schede indicano la fonte digitale usata per la verifica. Gli estratti da opere con storia redazionale complessa sono dichiarati come tali. `Le Grazie` non viene presentata come opera dotata di un testo definitivo.

## Avvio locale

Servire questa cartella con un server HTTP statico. Per esempio:

```sh
python3 -m http.server 8080
```

La PWA è progettata per funzionare anche sotto il percorso di GitHub Pages:

`/IV-anno/Letteratura/Foscolo-testi/`
